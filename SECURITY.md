# Security policy

Do not open a public issue containing credentials, tokens, private keys, local reports, or sensitive harness configuration.

For a suspected vulnerability in these scripts, use GitHub private vulnerability reporting when available. Include the affected version, platform, reproduction steps, and impact, but redact secrets and machine-specific private data.

Release archives intentionally exclude `backups/`, `reports/`, `dist/`, Git metadata, and common operating-system state. Review local changes before publishing a fork.
